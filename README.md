# Autograd Engine from Scratch

# Description
A minimal automatic differentiation engine built in Python.
Inspired by Andrej Karpathy’s micrograd, extended with:
- Multiple activation functions (ReLU, Sigmoid, Tanh)
- Custom training loop on a small dataset


# Features
- Scalar-based autograd engine
- Backpropagation using computation graph
- Activation functions: ReLU, Sigmoid, Tanh
- Neural network (MLP) implementation
- Gradient descent training

# Inspiration 
Inspired by Andrej Karpathy’s micrograd project.
This implementation was built as a learning exercise with modifications.
